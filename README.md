# Morwin Solutions Website

Existing static HTML source and gallery artwork for the Morwin Solutions painting services website.

## Files

- `index.html`: home page, copied from the existing website HTML.
- `morwin-textures/`: seven local texture images used by the home page.
- `morwin-gallery-preview.html`: existing project gallery preview.
- `gallery-cards/`: gallery SVG cards and supporting artwork.
- `references/gallery.html`: the original gallery layout reference.

The reference HTML expects its original home-page paths and logo file; it is preserved as a design reference rather than a runnable page in this folder.

## Preview locally

Open `index.html` or `morwin-gallery-preview.html` in a browser. Alternatively, run `python -m http.server 8000` from this directory and visit http://localhost:8000.

No package installation or build step is required. Some images and fonts load from external providers and need an internet connection.

## Current status

This repository preserves the available local source. It is not an export of the latest Canva design and does not include all subsequent manual Canva edits. The gallery HTML is an earlier three-column preview; the approved saved Canva gallery uses four columns.

The current editable design is https://www.canva.com/design/DAHXUa2lLj8/rEVDpLk8UE5Mje2x5OSMsw/edit.

Project imagery remains placeholder artwork until real photos and their project mapping are supplied. WhatsApp links in the existing source still need the confirmed phone number, and `hello@morwinsolutions.com` needs confirmation before publication. Navigation and gallery behavior should be verified before launch.

Importing this source into GitHub does not publish or synchronize the Canva website.
